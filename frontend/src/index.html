3-Tier Cloud-Native Topology

Engineered for high reliability, fault isolation, and independent horizontal scaling.

TIER 1: PRESENTATION

Web Portal & Reverse Proxy

  • Tech: Nginx Alpine (Non-Root UID 101)
  • Port: 80 (External) -> 8080 (Container)
  • Scaling: HPA 2 to 6 Pods
TIER 2: APPLICATION

REST API & Prometheus SDK

  • Tech: Node.js Express + prom-client
  • Port: 5000 (ClusterIP internal)
  • Metrics: Custom RED Method & DB Latency
TIER 3: DATA STORE

PostgreSQL Stateful Cluster

  • Tech: PostgreSQL 16 Alpine
  • Storage: PersistentVolumeClaim (PVC)
  • Resilience: StatefulSet with init seed
